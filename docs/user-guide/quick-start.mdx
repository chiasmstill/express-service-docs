# Быстрый старт

**Экспресс сервис** — курьерская служба для доставки документов и посылок по городу и области.
На этой странице описаны первые шаги: как зарегистрироваться, создать заказ и начать работу
с сервисом за 5 минут.

## Шаг 1. Регистрация

Чтобы оформлять заказы, вам нужен аккаунт. Регистрация занимает меньше минуты.

1. Перейдите на сайт **express-service.test**.
2. Нажмите кнопку **Зарегистрироваться** в правом верхнем углу.
3. Заполните форму:
   - Имя и фамилия
   - Адрес электронной почты
   - Пароль (не менее 8 символов)
4. Нажмите **Создать аккаунт** — письмо с подтверждением придёт на почту в течение 2 минут.

![Форма регистрации](/img/quick-start.svg)

:::tip Уже есть аккаунт?
Нажмите **Войти** и введите email с паролем. Если забыли пароль — воспользуйтесь ссылкой
**Восстановить пароль** на странице входа.
:::

## Шаг 2. Создание первого заказа

После входа в личный кабинет вы попадёте на главную страницу с обзором ваших заказов.
Чтобы оформить первую доставку:

1. Нажмите кнопку **Создать заказ** на главной странице.
2. Укажите адрес и контактные данные отправителя.
3. Укажите адрес и контактные данные получателя.
4. Выберите тип доставки: Стандарт, Экспресс или Ночная.
5. Подтвердите заказ и выберите удобный способ оплаты.

После оформления курьер свяжется с вами для уточнения деталей в течение 15 минут.

## Пример запроса к API

Если вы разрабатываете интеграцию, создайте заказ через API следующим запросом.
Метод `POST /orders` принимает данные отправителя, получателя, вес и тип доставки:

```http
POST /orders
Content-Type: application/json
Authorization: Bearer <ваш_токен>

{
  "sender": {
    "name": "Иванов Иван Иванович",
    "phone": "+7-900-123-45-67",
    "address": "Москва, ул. Ленина, 1, кв. 10"
  },
  "recipient": {
    "name": "Петрова Анна Сергеевна",
    "phone": "+7-900-765-43-21",
    "address": "Москва, пр. Мира, 42, офис 301"
  },
  "weight": 1.5,
  "service_type": "express"
}
```

В ответ сервис вернёт `id` созданного заказа и его начальный статус `accepted`.
Подробнее — в разделе [Разработчикам](/docs/api/overview).
