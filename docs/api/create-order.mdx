# Создание заказа

**Метод:** `POST /orders` · **Авторизация:** обязательна

Создаёт новый заказ на доставку. В запросе нужно передать данные отправителя, получателя,
вес посылки и тип доставки. В ответ сервис вернёт уникальный трек-номер заказа и начальный
статус `accepted`.

## Пример запроса

```http
POST https://api.express-service.test/v1/orders
Authorization: Bearer <ваш_токен>
Content-Type: application/json

{
  "sender": {
    "name": "Иванов Иван Иванович",
    "phone": "+7-900-123-45-67",
    "address": "Москва, ул. Ленина, 1, кв. 10"
  },
  "recipient": {
    "name": "Петрова Анна Сергеевна",
    "phone": "+7-900-765-43-21",
    "address": "Москва, пр. Мира, 42, офис 301"
  },
  "weight": 1.5,
  "service_type": "express"
}
```
