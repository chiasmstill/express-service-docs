# Список услуг

**Метод:** `GET /services` · **Авторизация:** не требуется

Возвращает список всех доступных видов доставки с названиями, описаниями и базовыми тарифами.
Метод открытый — его можно вызывать без токена, чтобы показать пользователю варианты
перед оформлением заказа.

Итоговая стоимость рассчитывается при создании заказа (`POST /orders`) с учётом веса и расстояния.

## Пример запроса

```http
GET https://api.express-service.test/v1/services
```

## Ответ — 200 OK

Ответ — массив объектов. Каждый объект описывает один вид доставки:
