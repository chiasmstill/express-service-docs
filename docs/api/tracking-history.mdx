# История отслеживания заказа

**Метод:** `GET /orders/{id}/tracking` · **Авторизация:** обязательна

Возвращает полную хронологию движения заказа по трек-номеру.

## Заголовки

<ParamsTable params={[
  { name: 'Authorization', type: 'string', required: true, in: 'header', description: 'Токен доступа', example: 'Bearer ваш_токен' },
]} />

## Path-параметры

<ParamsTable params={[
  { name: 'id', type: 'string', required: true, in: 'path', description: 'Трек-номер заказа, полученный при создании', example: 'ORD-20250325-00042' },
]} />

## Пример запроса

```http
GET https://api.express-service.test/v1/orders/ORD-20250325-00042/tracking
Authorization: Bearer <ваш_токен>
```
