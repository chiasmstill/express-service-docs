# Статус заказа

**Метод:** `GET /orders/{id}` · **Авторизация:** обязательна

Возвращает текущий статус заказа и прогнозируемое время доставки.
Используйте трек-номер (`id`), полученный при создании заказа.

]} />

## Path-параметры

<ParamsTable params={[
  { name: 'id', type: 'string', required: true, in: 'path', description: 'Трек-номер заказа, полученный при создании', example: 'ORD-20250325-00042' },
]} />

## Пример запроса

```http
GET https://api.express-service.test/v1/orders/ORD-20250325-00042
Authorization: Bearer <ваш_токен>
```
