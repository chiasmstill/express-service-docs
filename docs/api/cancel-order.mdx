# Отмена заказа

**Метод:** `DELETE /orders/{id}` · **Авторизация:** обязательна

Отменяет заказ по трек-номеру. Отмена возможна только если заказ находится
в статусе `accepted` или `waiting_courier` — то есть до момента,
когда курьер забрал посылку у отправителя.
