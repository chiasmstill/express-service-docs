# Список заказов

**Метод:** `GET /orders` · **Авторизация:** обязательна

Возвращает список заказов текущего пользователя с фильтрацией и пагинацией.

## Query-параметры

<ParamsTable params={[
  { name: 'status', type: 'string', required: false, in: 'query', description: 'Фильтр по статусу заказа. Возможные значения: accepted, waiting_courier, picked_up, in_transit, delivered, failed_delivery, returned', example: 'in_transit' },
  { name: 'from', type: 'string', required: false, in: 'query', description: 'Начало периода (формат: ДД.ММ.ГГГГ)', example: '01.01.2025' },
  { name: 'to', type: 'string', required: false, in: 'query', description: 'Конец периода (формат: ДД.ММ.ГГГГ)', example: '31.12.2025' },
  { name: 'limit', type: 'integer', required: false, in: 'query', description: 'Количество записей на странице (по умолчанию 20, минимум 1, максимум 100)', example: '20' },
  { name: 'offset', type: 'integer', required: false, in: 'query', description: 'Смещение (по умолчанию 0)', example: '0' },
]} />

## Пример запроса

```http
GET https://api.express-service.test/v1/orders?status=in_transit&limit=10
Authorization: Bearer <ваш_токен>
```


## Ответ — 200 OK

```json
{
  "total": 142,
  "limit": 10,
  "offset": 0,
  "items": [
    { "id": "ORD-20250325-00042", "status": "in_transit", "service_type": "express", "created_at": "25.03.2025 10:00" },
    { "id": "ORD-20250324-00038", "status": "in_transit", "service_type": "standart", "created_at": "24.03.2025 14:20" }
  ]
}
```

:::note
Чтобы получить следующую страницу, увеличьте значение `offset` на значение `limit`. Например, если `limit=10` и `offset=0`, следующая страница будет `offset=10`.
:::
