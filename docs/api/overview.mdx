# API Экспресс сервис

REST API компании **Экспресс сервис** открывает программный доступ к возможностям курьерской службы.
С его помощью вы можете автоматизировать создание заказов, отслеживать доставки в реальном времени
и получать актуальный список тарифов — всё это без ручного взаимодействия с сайтом.

API подходит для интеграции с интернет-магазинами, CRM-системами, складскими платформами
и любыми другими сервисами, которым нужна автоматическая работа с доставкой.

## Доступные методы

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `POST` | [`/orders`](./create-order) | Создать новый заказ |
| `GET` | [`/orders/{id}`](./get-order) | Получить статус заказа |
| `GET` | [`/services`](./list-services) | Получить список услуг и тарифов |

## Базовый URL

```
https://api.express-service.test/v1
```

Все запросы отправляются на этот адрес. Версия API (`v1`) указывается в пути —
это гарантирует стабильность интеграции при выпуске новых версий.

## Аутентификация

Большинство методов требуют токен доступа. Исключение — `GET /services`, он доступен без авторизации.

Токен передаётся в заголовке каждого запроса:

```http
Authorization: Bearer <ваш_токен>
```

### Как получить токен

1. Войдите в личный кабинет на сайте **express-service.test**.
2. Нажмите на имя в правом верхнем углу и перейдите в раздел **Профиль**.
3. Откройте вкладку **API**.
4. Нажмите кнопку **Сгенерировать токен**.
5. Скопируйте токен — он отображается только один раз.

:::caution Храните токен в безопасности
Не публикуйте токен в открытом коде и репозиториях. Если токен скомпрометирован,
вернитесь в **Профиль → API** и сгенерируйте новый — старый станет недействительным.
:::

## Формат дат

Все даты передаются по московскому времени (UTC+3) в формате `ДД.ММ.ГГГГ ЧЧ:ММ`.

**Пример:** `25.03.2025 14:30`

## Формат ошибок

При ошибке сервер возвращает JSON-объект:

```json
{
  "code": "VALIDATION_ERROR",
  "message": "Ошибка валидации входных данных",
  "details": ["weight: значение должно быть от 0.1 до 30"]
}
```

| Поле | Описание |
|------|----------|
| `code` | Машиночитаемый код ошибки |
| `message` | Описание ошибки на русском |
| `details` | Дополнительные сведения (необязательно) |
